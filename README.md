# Service-Booking-System
The Service Booking System is a web-based platform that allows users to easily find, book, and manage professional services online. Instead of contacting service providers manually, users can browse available services, check provider details, select a convenient date and time, and make a booking through the platform.  The system is designed using a microservices architecture, where different functionalities are handled by independent services such as User Management, Authentication, Service Management, Booking, Payment, and Rating. An API Gateway acts as the main entry point and communicates with the individual backend services.  
Key Features 
👤 User Registration & Login – Users can create accounts and securely log in. 
🔍 Service Discovery – Browse and search for available services. 
📅 Service Booking – Select a service, date, and time and create a booking. 
👨‍🔧 Service Provider Management – Manage service providers and their offered services. 
💳 Payment Management – Handle payments associated with bookings. 
⭐ Ratings & Reviews – Users can rate and review completed services. 
📋 Booking Management – View, update, and manage booking status. 
🔐 Authentication & Authorization – Protect user accounts and service APIs. 
🌐 API Gateway – Provides a single entry point to communicate with the different microservices.
